## 🌟 About The Project

Ever wondered how a computer can challenge your guessing skills?

**Number Guessing Game** is a Python-based console game where the computer
generates a secret number, and your mission is to discover it!

With every guess, you receive a clue that guides you closer to the answer.
Think logically, make your next move, and keep guessing until you win! 🏆

This project represents another step in my journey of learning Python
and transforming programming concepts into interactive applications.

## 🧠 The Logic Behind The Game

The game follows a simple but engaging process:

1. **Generate** — The computer selects a random number.
2. **Predict** — The player enters a guess.
3. **Analyze** — Python compares the guess with the secret number.
4. **Guide** — The game provides a higher-or-lower hint.
5. **Win** — The player succeeds by guessing the correct number!
