# 🎮 Number Guessing Game Using Python

A fun and interactive number guessing game built using Python! 🐍

In this game, the computer generates a random number, and the player tries to guess it. After each guess, the game provides helpful hints to tell whether the guess is too high or too low. Keep guessing until you find the correct number!

## ✨ Features

- 🎲 Random number generation
- ⌨️ User input for guessing numbers
- 💡 Helpful hints for each guess
- 🏆 Congratulatory message when the correct number is guessed
- 🔄 Replay option (if implemented)

## 🛠️ Technologies Used

- Python 🐍
- Random module
- Visual Studio Code (VS Code)
